# Recipe: Sector-Based Hub / Metaspace

Prefer connected sectors over one enormous always-live world when it improves compatibility and density.

Capabilities:
- sector streaming / transitions
- hub navigation
- fast travel
- persistent player/world state
- per-sector recipes
- asset streaming/LOD
- day/night where meaningful

Gate: two distinct sectors connected by a working transition, persistent state across transition, and one activity in each sector.
