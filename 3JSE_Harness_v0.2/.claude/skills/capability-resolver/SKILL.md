# Capability Resolver

Translate user intent into concrete capabilities before architecture.\n\nExamples: `tropical surfing game` -> ocean, waves, buoyancy, board physics, humanoid, animation, tricks, third-person camera, vegetation, terrain, audio.\n\nFor each capability query `.agents/registry/capabilities.json`, project code/assets, then Vendor Router. Keep the list minimal: do not add systems merely because they sound engine-like.
