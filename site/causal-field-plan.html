Stop accumulating splat papers

3JSE does not ship a Gaussian physics engine.
It ships a response-function field.

Gaussian splats are the spectacular projection of hidden state — not the state itself. The invention is a baked material response \(R(\text{state}, \text{environment}, \text{direction})\) evaluated on a coarse field and projected into photons, contact, language queries and vendor FX.

01 · Invention

The one sentence that survives three review passes

Copilot found the adjacency graph. ChatGPT named the join. The papers confirm the pieces exist separately. 3JSE’s contribution is the product of those pieces as an engine abstraction — not another 3DGS paper.

Build a multiresolution causal field whose live state and baked response coefficients project into Gaussians, continuum simulation, Rapier, audio, semantics and AI. Gaussian splatting makes the visible projection practical. The field is the primitive.

What already exists

  • Constitutive mixtures on Gaussians (OmniPhysGS)
  • Time-varying scalars under a momentum residual (PIDG)
  • Language → physics proxies → splat skin (PhysTalk)
  • Separate combustion grid → fire/smoke/char (FieryGS)
  • Cheap semantic latents on the kernel (Feature Splatting / LangSplat V2)
  • Feed-forward \(E,\nu,\rho\) volumes (VoMP)
  • Live WebGPU buffers (Brush) and live mutate (Playground)

What nobody generalized

  • A compact R(state, env, direction) as a first-class type
  • Expert weights that are functions of live state
  • One field update → visual + mechanical + semantic + acoustic
  • Dual resolution as a law, not a paper trick
  • Agent verbs that write field state, never render objects
  • Offline CUDA compilers vs a tiny web evaluator

03 · Dual reality

Phenomenal world and causal world, co-located

A game already has two synchronized realities. Splats become interesting when they are the bridge — not when they are another asset type.

04 · Primitive

ResponseElement — not “Gaussian with more attributes”

@3jse/fieldIR
interface ResponseElement {
  // identity
  semantic: SemanticLatent
  materialPrior: MaterialDistribution
  uncertainty: Uncertainty

  // slowly changing or baked
  response: ResponseCoefficients   // palette index + small latent

  // rapidly changing
  state: {
    temperature: number
    moisture: number
    density: number
    strain: Tensor
    velocity: Vector3
    phase: number
    fuel: number
  }

  // projections (bindings, not copies of the world)
  visualBinding: VisualBinding     // splat cluster / mesh / vendor FX
  physicsBinding: PhysicsBinding   // Rapier collider / MPM subset
}

The revolutionary member is response. Not friction = 0.7. Not even E, ν, ρ as the whole story. A function:

R(state, environment, direction) → {
  visual:     { sh, opacity, emission, covariance }
  mechanical: { friction, stiffness, cohesion, viscosity }
  chemical:   { ignition, burnRate, smokeYield }
  acoustic:   { absorption, impact }
  semantic:   { affordances }
}
05 · Manifold walk

Steal OmniPhysGS’s experts. Make the weights a function of state.

Do not search for one universal constitutive equation. Keep a small behavior basis. The 3JSE extension — the part that is not in OmniPhysGS — is that mixture weights move when the field moves.

Runtime expert basis (four, not twelve)

Elastic · Granular · Cohesive · Fluid-like

Plastic / brittle / porous / viscous fold into these or wait for a second card generation. Player runtime does not host 12 networks.

Baked walker

weights = W(
  temperature,
  moisture,
  pressure,
  density,
  phase,
  strain
)

W is fitted offline (compiler). Evaluated every tick (evaluator).

08 · Adjacency

The four-project join, plus the carrier

OmniPhysGS ICLR 2025

12-expert constitutive mix per Gaussian. Material is a location in behavior space. Mix is static after training.

Steal the basis. Do not ship the trainer.

PIDG AAAI 2026

Lagrangian point, time-varying \(E,\nu,\rho\), Cauchy momentum residual. Closest “field evolves.”

Steal the scalars. Do not set splat count = particle count.

PhysTalk arXiv 2512.24986

LLM emits code against physics proxies. Viewport is witness. Matches harness doctrine.

Steal the verb surface. Genesis is not the 3JSE backend.

FieryGS ICLR 2026 · Apache-2.0

MLLM paint + volumetric combustion grid ≠ splat count + project fire/smoke/char. Public repo: PKU-VCL-Geometry/FieryGS — audit completeness before any copy.

Steal the loop. Combustion is one card, not a product.

Feature Splatting / LangSplat V2 supply the semantic carrier and the compression lesson: 32-D (or a dictionary) beats 768-D per Gaussian.

13 · Proof

Only three experimental demos

If A works we have a ResponseElement. If B works on the same code we have a general field. If C works we have emergence. Stop there.

Demo Asnow tile

20 m × 20 m. State: temperature, moisture, density, compression.

Outputs: SH/color, opacity, covariance, ski friction, penetration, spray, sound parameter.

Sweep −15 °C → +2 °C through powder → packed → wet → slush → crust without changing materialId.

Fail = five prefabs.

Demo Brainy trail

Same evaluator. Rain writes one number: moisture.

That number must darken dirt, raise specularity, cut dust, raise splash, drop bearing strength, cut tire grip, allow ruts.

Couple Gaia color and Rapier friction from the same cell.

Fail = a “wet dirt” material swap.

Demo Cforest fire

Sun, wind, temperature, fuel, moisture. Ember → heat → evaporation → ignition response → combustion → neighbor.

No SetTreeOnFire(). Spot fire downwind is the evidence, plus a field dump — not an orange screenshot.

Project emission/opacity onto existing VFX / Tiamat-class smoke.

Fail = a fire AI.

16 · After the three demos

The same card, stranger worlds

Avalanche

Layered snowpack walks the manifold under load and temperature.

Rockfall

Directional brittle response + accumulated stress.

Erosion

Soil × water velocity × saturation → transport.

Landslide

Saturation walks cohesive → fluid until shear fails.

Growth

Moisture / sun / nutrient → biomass on the same cells Dryad reads.

Tree bend

Wind evaluates directional elasticity; Gaia/Dryad instances follow.

Tire wear

TireResponse × SurfaceResponse; heat and tread live on the field.

Ice crack

Gradient + stress evolve brittle weights.

Fog / cloud

Phase + optical projection. Cousin of Poseidon foam.

Ocean foam

Aeration state writes Poseidon’s foam layer instead of a second FX system.

Rust

Slow moisture × exposure integral. Weathering is a long tick.

NPC sense

Agents query the same field players see projected. No anonymous triangles.
